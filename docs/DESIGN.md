# Дизайн web-gradebook 0.2

Ревизия интерфейса после первой версии: вместо универсального синего SaaS-дашборда — рабочий
журнал преподавателя. Документ фиксирует направление, токены и решения, чтобы следующие экраны
не расползались обратно в «карточки с мягкими тенями».

## Задача и контекст

Преподаватель ведёт несколько предметов, на паре стоит с телефоном в одной руке. Нужно открыть
предмет, выбрать группу, найти занятие, отметить явку и баллы. Второй сценарий — за неделю до
зачёта посмотреть, кто проваливается.

Отсюда два режима: **быстрый ввод** (крупные строки, минимум украшений) и **разбор** (цифры,
рейтинг, распределение). Один и тот же визуальный язык — как страница бумажного журнала: поля,
линейки, подписи от руки не нужны.

Визуальная преемственность — с прошлого проекта автора `web-schedule`: тёплая бумажная основа,
чернильный текст, приглушённые акценты. Здесь она доведена до более строгого редакционного вида.

## Токены

Светлая тема:

| Роль | Значение | Где |
| :--- | :--- | :--- |
| фон | `#f2f1ec` | страницы, поля между блоками |
| поверхность | `#fbfaf7` | листы журнала, карточки, шторки |
| линия | `#ddd9cf` | волосяные разделители |
| чернила | `#1c1a16` | текст, основная кнопка, FAB |
| приглушённый | `#575146` | вторичный текст |
| слабый | `#8f887a` | подписи, метаданные |
| глина | `#a54d28` | активные вкладки, дедлайны, действия |
| мох | `#52683d` | «был», успех, лабораторные |
| сталь | `#3c5765` | лекции, нейтральные метки |
| подгруппа 1 | `#6b83a6` | синий, не путается с оценкой |
| подгруппа 2 | `#947a97` | сливовый |
| подгруппа 3 | `#678b86` | бирюзовый |
| тревога | `#a53226` | ошибки, кламп балла |

Тёмная тема — не инверсия, а другой материал: фон `#151412`, поверхность `#1d1b18`, чернила
`#efece4`, глина `#d99268`, мох `#a9bd8a`, сталь `#9cb7c4`, подгруппы — `#aab8cf`, `#c4b0c6`,
`#9bc0bb`. Основная кнопка в тёмной теме становится светлой (это по-прежнему «чернила», просто
бумага и чернила поменялись местами).

Правила:

- синего нет вообще;
- одна основная кнопка на экран — чернильная; глина только для состояния, а не для фона CTA;
- никаких градиентов, свечения, стеклянных панелей и «мягких теней под каждой карточкой»;
- тень только у плавающих слоёв: шторка, FAB, тост.

## Типографика

Две семьи, обе с кириллицей и self-hosted (без сети и без Google Fonts в рантайме):

- **Literata** — заголовки экранов, названия предметов и студентов, крупные проценты.
  Это книжная антиква: журнал, а не дашборд. Оптический размер включён.
- **Golos Text** — интерфейс, подписи, числа. Русский гротеск с хорошими табличными цифрами.

Шкала: 46/38/30 — крупные числа; 22–26 — заголовки; 19 — названия предметов; 15 — строки;
13 — подписи; 12 — метаданные; 11 — служебное. Никаких ALL CAPS-надзаголовков: подписи
предложением, обычным регистром.

Числа всегда `tnum`, чтобы проценты и баллы не дёргались при вводе.

## Сетка и структура

Одна колонка, 20 px поля, max-width 600 px. Основной приём — **лист с волосяными линейками**:
несколько строк живут в одном прямоугольнике с разделителями, а не в отдельных карточках.
Карточка — только там, где объект действительно отдельная сущность (предмет, занятие в списке).

Заголовок экрана — липкий, непрозрачный, с нижней линейкой. Крупная антиква слева, действия
справа. Никаких хлебных крошек и дублирующих заголовков.

Порядок на экране предмета отражает рабочий процесс:

```
[название предмета]                         ⚙
[Группа: ПИ-21                        ⌄]
 Журнал | Студенты | Сводка
 Лекция 2   Практика 3   Лабораторная 2
 ┌─────────────────────────────────┐
 │ ● Лабораторная 1          82%   │
 │   2 сессии · макс 100 · вес 2  │
 │   просрочен на 14 дней · 10 ноя │
 └─────────────────────────────────┘
```

Сначала предмет, затем группа, затем вид занятия, затем занятие. Это ровно тот путь, который
преподаватель проходит перед парой; раньше вид занятия и группа были спрятаны в разных местах.

## Подгруппы цветом

Цвет — не декор, а признак принадлежности:

1. подгруппа 1 — глина,
2. подгруппа 2 — мох,
3. подгруппа 3 — сталь.

В списке студентов у каждой строки цветная полоса слева. На экране выставления показывается
**вся группа**: сначала активная подгруппа (её можно отмечать), ниже — остальные, приглушённые,
со своей датой и уже выставленным баллом. Так видно и тех, кого отмечаешь, и весь контекст группы,
не переключаясь между экранами.

## Быстрый путь к баллу

Главный сценарий — поставить балл за лабу, стоя на паре. Поэтому:

- отдельная вкладка **«Группы»** — это и есть вход в журнал: группа → предмет → занятие → балл.
  На экране группы сразу видно средний балл, предметы с оценками и состав.
- студенты живут в группе, а не в предмете: добавили один раз — зачислили в несколько предметов.
  Новый студент автоматически попадает во все предметы группы.
- на главной остались только предметы: поиск и фильтр «Активные / Архив» появляются, когда
  предметов больше трёх или есть архив. Ничего лишнего.
- в журнале предмета у каждого занятия сразу видны **строки сессий с датами**: «пт, 23 окт ·
  Подгруппа 1 · 10/11». Тап по строке открывает выставление; шапка занятия ведёт в настройки.
- прямо на экране сессии — **«Отметить всех»** с отменой в тосте. Массовая кнопка снова доступна,
  но ошибочное нажатие исправляется одним тапом «Отменить».
- «Максимум всем» остаётся только в меню «…» с подтверждением: это редкое и разрушительное действие.
- в списках группы и сессии у студентов есть **порядковый номер**: в группе — по алфавиту,
  в сессии — по списку подгруппы.

## Цвет и оценка

- Шкала: `0–50 → 2` (красный), `51–70 → 3` (оранжевый), `71–85 → 4` (жёлтый), `86–100 → 5`
  (зелёный). Цвета — отдельные токены `--color-grade2…grade5`, одинаковые в светлой и тёмной теме.
- На экране выставления цвет виден прямо в строке: подсчёркивание и число балла, рядом — оценка
  2–5. Для предметов «сдал / не сдал» вместо числа стоит зелёная галочка или красный крест.
- Итог студента, средние по предметам и рейтинг окрашены той же шкалой; на карточках предметов и
  групп — компактный чип оценки.

## Профиль студента

- Тап по студенту в группе открывает профиль по всем предметам, а не только текущую дисциплину.
- Сверху — средний балл, оценка и посещаемость; ниже предметы с итогом и переходом в журнал.
- Работы сгруппированы по видам: практики, лабораторные, лекции. У каждой строки — предмет, дата,
  вес и цветной балл; для «сдал / не сдал» — зелёный/красный статус.
- Дубли убраны: занятие показывается один раз, занятия других групп и пустые сессии не попадают.

## Другая подгруппа

На экране лабораторной активной подгруппы ниже видна вторая: дата её занятия, явка (зелёная
галочка или красный крест) и баллы с оценками в цветах шкалы. Так преподаватель сверяет обе
подгруппы, не переключаясь между сессиями.

## Лекции — только посещаемость

Лекции не входят в итоговый балл и не имеют «сдал / не сдал»:

- на экране сессии нет полей балла и максимума, только отметки «был / не был»;
- в журнале у лекции нет процента: справа `было 19/22`, в подписи «только посещаемость»;
- в карточке студента отдельная строка «Лекции 1 / 3» и полоса посещаемости;
- в настройках предмета у лекции нет веса; в формуле итога участвуют только практики и лабораторные.

## Группы как сущность

Группа — верхний уровень навигации. На вкладке «Группы» — список с числом студентов, предметов и
средним баллом. Внутри группы:

- состав с номерами и числом предметов у каждого;
- предметы с средним баллом и цветной оценкой, тап открывает журнал выбранной группы;
- «Добавить» — существующие студенты, новые или список;
- «Зачислить» — предмет, в который попадут все студенты группы.

## Группы-бейджи

Группы в предмете переключаются бейджами под заголовком: имя и число студентов, активный —
чернильный. Рядом кнопка «+»: можно зачислить уже существующую группу целиком. Никаких выпадающих
списков ради выбора группы — один тап.

## Лабораторные и подгруппы

- Одна лабораторная — это одно занятие, даже если подгруппы ходят в разные дни: у «Лабораторной 1»
  две сессии (подгруппа 1 и 2), а не «ЛР1» и «ЛР2» у разных подгрупп.
- Импорт расписания объединяет даты лабораторных в блоки по числу подгрупп.
- Если подгруппы у группы не заданы, сессия показывает всю группу; студент без подгруппы тоже
  попадает в список, а не исчезает.

## Таблица журнала

- Вкладка «Таблица» — отдельные таблицы по видам: лабораторные, практики, лекции. Вид без занятий
  не показывается.
- Колонка — занятие («Лабораторная 1»), название по центру, под ней подколонки дат подгрупп.
- Подгруппы заметны цветом клетки и строки; это синий/сливовый, а не «плохой/хороший» красный/зелёный.
- Клетка разделена: сверху явка (контрастный кружок и «был / нет»), снизу балл с цветной
  оценкой; нажатия крупные.
- Итог — процент и оценка рядом, без второй строки.
- Липкие шапка, колонка имён и итоговая строка; таблица прокручивается внутри, страница — нет.
- Внизу по каждой колонке — «было / всего» и средний процент; справа — итог по виду.
- Desktop: контейнер 980 px; телефон — компактные вкладки видов и горизонтальная прокрутка.

## Навигация

Нижняя навигация: **Предметы, Группы, Статистика, Настройки** — и видна на всех экранах, включая
студента, занятие и выставление. «Данные» открываются из настроек, чтобы не занимать вкладку.
Активная вкладка определяется по разделу: детальные экраны предмета подсвечивают «Предметы»,
экраны группы — «Группы».

## Компоненты

- `Select` — не нативный `<select>`, а кнопка с текущим значением и шторка со списком: одинаково
  в светлой и тёмной теме, крупные строки, галочка у выбранного.
- Иконки — `lucide-react` через обёртку `Icon` (единый штрих 1.8, размеры 13–26).
- Tailwind CSS 4: токены объявлены в `@theme` прямо в `src/index.css`, без `tailwind.config.js`.
- `Switch` — трек 44×26, ручка 20 px с фиксированным `left: 2px` и сдвигом на 20 px; раньше ручка
  выезжала за трек на 18 px.
- Тосты — чернильные, с необязательным действием («Отменить»), живут 6 секунд для отмены.
- Даты в журнале — компактные «пт, 23 окт», год не дублируется.
- Длинные названия предметов в статистике обрезаются многоточием; выбор предмета занимает всю
  ширину, группы переключаются бейджами под ним — фильтры не ломают вёрстку даже на 320 px.

## Безопасность действий

- «Отметить всех» — один тап, но с отменой в тосте; «Максимум всем» — меню и подтверждение.
- Удаление занятия, сессии, предмета — только через подтверждение.
- PIN-код и смена PIN — отдельные шторки с явными кнопками.

## Движение

Анимируются только слои, которые отвечают на действие: шторка выезжает снизу, тост появляется.
Смены экранов не сопровождаются одинаковым fade-and-slide для каждой секции. `prefers-reduced-motion`
отключает всё.

## Доступность

- зум не запрещён (`user-scalable` убран);
- тач-цели: кнопки 44–56 px, строка выставления 64 px;
- видимый `:focus-visible` глобально;
- семантические `button`/`a`/`label`, `aria-label` у иконочных кнопок;
- тосты — `role="status"` + `aria-live="polite"`;
- заголовки h1 → h2, ссылка «К содержанию»;
- `touch-action: manipulation`, `overscroll-behavior: contain` в шторках.

## Проверка

- e2e-смоук (`npm run test:e2e`) проверяет новый поток: группа → вид → занятие → сессия, отсутствие
  массовых кнопок на экране, подтверждение через меню, всю группу в сессии.
- Скриншоты 390×844 и 320×700, светлая и тёмная тема, без горизонтального скролла.
- Ревью по Web Interface Guidelines: убраны `user-scalable=no`, добавлены `aria-live`,
  `overscroll-behavior`, `touch-action`, `text-wrap: balance`, ссылка «К содержанию».

## Источники направления

- Скилл `frontend-design` — анти-шаблонные правила, типографика, самокритика.
